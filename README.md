# Task Manager API

Учебный проект на FastAPI для создания и получения задач.

API позволяет создавать задачи, хранить их во временной памяти приложения и получать созданные задачи по идентификатору.

База данных в проекте не используется.

## Реализованный функционал

В приложении реализованы два эндпоинта:

- `POST /tasks` — создание новой задачи;
- `GET /tasks/{task_id}` — получение задачи по её идентификатору.

## Создание задачи

Для создания задачи используется:

`POST /tasks`

Тело запроса содержит следующие поля:

- `title` — обязательная строка длиной от 3 до 100 символов;
- `description` — необязательная строка с описанием задачи;
- `priority` — обязательное целое число от 1 до 5.

После успешного создания задача получает уникальный идентификатор `id`.

Пример запроса:

```json
{
  "title": "Изучить FastAPI",
  "description": "Выполнить домашнее задание",
  "priority": 3
}
```

Пример ответа:

```json
{
  "title": "Изучить FastAPI",
  "description": "Выполнить домашнее задание",
  "priority": 3,
  "id": 1
}
```

При успешном создании сервер возвращает:

`201 Created`

Если переданные данные не соответствуют требованиям модели, сервер возвращает:

`422 Unprocessable Content`

## Получение задачи

Для получения задачи используется:

`GET /tasks/{task_id}`

Где `task_id` — идентификатор задачи.

Например:

`GET /tasks/1`

Если задача существует, сервер возвращает:

`200 OK`

и данные найденной задачи.

Если задачи с указанным идентификатором нет, сервер возвращает:

`404 Not Found`

Пример ответа:

```json
{
  "detail": "Task not found"
}
```

Если вместо числового идентификатора передано некорректное значение, FastAPI возвращает ошибку валидации:

`422 Unprocessable Content`

## Pydantic-модели

В проекте используются две модели.

### TaskCreate

Модель используется при создании новой задачи.

Поля:

- `title` — обязательная строка длиной от 3 до 100 символов;
- `description` — необязательное описание задачи;
- `priority` — обязательное целое число от 1 до 5.

### TaskResponse

Модель используется для ответа API.

Она содержит:

- `title`;
- `description`;
- `priority`;
- `id` — уникальный идентификатор задачи.

Эндпоинт 1:

Назначение: создание новой задачи.

## Как запустить проект

Ниже приведена инструкция для запуска проекта после его скачивания.

### 1. Создать виртуальное окружение

```bash
python3 -m venv .venv
```

Команда создаёт отдельное Python-окружение для проекта.

### 2. Активировать виртуальное окружение

```bash
source .venv/bin/activate
```

После активации перед строкой терминала появится:

```text
(.venv)
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

Команда устанавливает необходимые для проекта Python-библиотеки из файла `requirements.txt`.

### 4. Запустить приложение

```bash
uvicorn main:app --reload
```

Здесь:

- `uvicorn` — сервер для запуска FastAPI;
- `main` — файл `main.py`;
- `app` — объект FastAPI внутри файла;
- `--reload` — автоматический перезапуск сервера после изменения кода.

### 5. Открыть Swagger UI

После запуска приложения открыть в браузере:

`http://127.0.0.1:8000/docs`
